# Giallo Oro Gioielli — shop prototype

Clickable IT/EN prototype: catalogue, product pages with certificates, bank-transfer checkout, 48h boutique viewing holds.

Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch → main / root).

Demo state is stored in the browser (localStorage). Clear site data in the browser to start over.

Product photos: Unsplash (free licence) and gialloorogioielli.com.
