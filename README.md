# Giallo Oro Gioielli — shop prototype

Clickable IT/EN prototype: catalogue, product pages with certificates, bank-transfer checkout, 48h boutique viewing holds, staff console.

Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch → main / root).

Demo state is stored in the browser (localStorage). Use **Staff → Reset demo** to start over.

Product photos: Unsplash (free licence) and gialloorogioielli.com.
